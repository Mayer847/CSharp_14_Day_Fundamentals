# Day 1: Program Flow and Console IO


## Child-sized explanation

The computer reads instructions from top to bottom. A variable is a labeled box. Input places something in a box; output shows something to the user.

## Learn

- `Console.WriteLine` outputs text.
- `Console.ReadLine` returns text or `null`.
- String interpolation inserts values: `$"Hello {name}"`.
- The compiler catches invalid syntax before the program runs.

## Challenge

Ask for a name, current role, and target role. Print a three-line career card. If an answer is blank, use `Not provided`.

## Stretch

Add today's date using `DateTime.Today`.
