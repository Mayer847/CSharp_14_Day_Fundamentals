# Day 7: Classes and Objects


## Core idea

A class is a blueprint. An object is one created thing. A useful class keeps related data and behavior together.

## Learn

- Properties describe state.
- Constructors create valid objects.
- Methods express behavior.
- `required` forces callers to initialize essential properties.
- A class should represent a meaningful concept, not merely hide variables.

## Challenge

Create a `JobApplication` class with company, role, match score, status, and an `IsPriority()` method. Create three objects and print priority applications.
